# Internal Components

| Path | Purpose |
|---|---|
| `setup.nu` | Stable user-facing entry point |
| `setup-main.nu` | Main setup transaction |
| `bootstrap.sh` | Linux/macOS bootstrap used when Nushell is not installed or core prerequisites must be prepared |
| `bootstrap.ps1` | Windows prerequisite/runtime preparation |
| `scripts/modules/` | Shared synchronization, safety, profile, and runtime logic |
| `scripts/` | User-command implementations and tests |
| `profiles/` | Workstation/laptop/server/minimal feature policy |
| `tools/cloudwins/` | Rust Cloud-wins engine |
| `docs/wiki/` | Long-lived English documentation |
